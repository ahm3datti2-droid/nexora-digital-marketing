# NEXORA Digital Marketing

موقع وكالة NEXORA للتسويق الرقمي + لوحة تحكم كاملة، مبني على **Cloudflare Workers + D1** بدون أي مكتبات خارجية.

> Beyond Digital. Beyond Limits.

## المميزات

**الموقع العام (عربي RTL، متجاوب مع الموبايل)**
- الواجهة الرئيسية، الخدمات، من نحن، طريقة الشغل، الأعمال (مع فلترة)، الباقات، آراء العملاء، الأسئلة الشائعة
- فورم طلب استشارة (يتحفظ في قاعدة البيانات) + اشتراك في النشرة البريدية
- زر واتساب عائم، روابط السوشيال، SEO و Open Graph، PWA manifest
- كل المحتوى قابل للتعديل من لوحة التحكم (الأقسام الفاضية بتختفي تلقائيًا)

**لوحة التحكم `/admin/`**
- إحصائيات + أحدث الطلبات
- إدارة الطلبات: بحث، فلترة بالحالة، ملاحظات، واتساب مباشر، تصدير CSV
- إدارة الخدمات، الأعمال، الباقات، آراء العملاء، الأسئلة الشائعة (إضافة/تعديل/إخفاء/حذف)
- إعدادات الموقع (العناوين، أرقام التواصل، السوشيال، أرقام الإنجازات)
- المشتركين، تغيير كلمة المرور

**الأمان**
- كلمات المرور مشفّرة PBKDF2-SHA256 (100,000 دورة) + salt
- جلسات بكوكي HttpOnly / Secure / SameSite=Strict، والتوكن متخزن كـ hash
- حماية من تخمين كلمة المرور (8 محاولات / 15 دقيقة) وrate limit لفورم التواصل
- فحص Origin ضد CSRF، Content-Security-Policy صارمة، Honeypot ضد السبام
- حساب المدير الأول بيتعمل بكود إعداد لمرة واحدة فقط

## الهيكل

```
src/worker.js            ← الـ API + الهيدرز الأمنية
public/                  ← الموقع (HTML/CSS/JS)
public/admin/            ← لوحة التحكم
migrations/0001_init.sql ← جداول قاعدة البيانات + المحتوى المبدئي
test/                    ← اختبارات (node test/run.mjs)
wrangler.jsonc           ← إعدادات Cloudflare
```

## النشر

متصل بـ Cloudflare Workers Builds: أي `push` على فرع `main` بيتنشر تلقائيًا.
قاعدة البيانات: D1 `nexora-db`.

لإضافة جداول جديدة: ضيف ملف `migrations/0002_xxx.sql` وغيّر Deploy command إلى `npm run deploy`.

## الاختبار

```
node --no-warnings test/run.mjs
```
